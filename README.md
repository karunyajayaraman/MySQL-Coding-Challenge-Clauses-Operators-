# MySQL-Coding-Challenge-Clauses & Operators

This repository contains MySQL practice exercises covering SQL clauses and operators commonly used in data analysis and database management.

## Topics Covered
- SELECT
- WHERE
- DISTINCT & AS 
- LIMIT
- BETWEEN/NOT BETWEEN
- LIKE/NOT LIKE
- IS NULL/NOT NULL
- IN/NOT IN
- Comparison Operators
- Arithmetic Operators
- Logical Operators (AND, OR, NOT)

## Tools Used
- MySQL Workbench
- MySQL
